Die Kartenseiten („Karte“, „Verschwundene Steine“, „Amtliche Grenzpunkte“) laden das Kartenprogramm Leaflet vom Dienst unpkg.com. Erst wenn Sie einen solchen Link anklicken, verbindet sich Ihr Browser mit Google (Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland). Dann gilt die Datenschutzerklärung von Google. Das Gleiche gilt für alle anderen Links auf fremde Websites.

6. Was nur in Ihrem Browser gespeichert wird

Einige Funktionen speichern Daten ausschließlich auf Ihrem Gerät. Sie werden nicht an mich oder Dritte übertragen:

  • Offline-Paket: Wenn Sie auf der Karte das Offline-Paket laden, speichert Ihr Browser die Karte, die Daten und die Kartenbilder, damit sie auch ohne Netz im Gelände funktionieren.
  • Fundnotizen: Notizen, die Sie auf der Karte zu einem Stein eintragen, bleiben in Ihrem Browser.
  • Ihr Standort: Wenn Sie auf der Karte die Standortanzeige einschalten, fragt Ihr Browser um Erlaubnis. Der Standort wird nur auf Ihrem Gerät verwendet, um Ihre Position und den Weg zum nächsten Stein anzuzeigen. Er wird nicht übertragen und nicht gespeichert.

Diese Speicherung ist für die Funktionen, die Sie selbst aufrufen, unbedingt erforderlich (§ 25 Abs. 2 Nr. 2 TDDDG). Sie können die Daten jederzeit löschen, indem Sie in Ihrem Browser die Websitedaten für beierstettel.de entfernen.
